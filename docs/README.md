# Documentation Pack

This folder contains submission-ready documentation artifacts and screenshot evidence for the assignment.

## Human Touch Checklist

To make the final submission feel authentic (not auto-generated), add these while preparing PDF/video:

1. Team voice: write 4-6 lines in your own words about why you chose this architecture.
2. Trade-offs: mention one thing you simplified (for time) and one thing you improved beyond baseline.
3. Real debugging story: include at least 2 issues you personally hit and how you fixed them.
4. Demo narration: explain what you are doing while running commands, not just showing outputs.
5. Reflection: add a short "what we learned" section at the end of the PDF.

## Structure

- `api/API_DOCUMENTATION.md` - API reference and Postman/OpenAPI notes
- `architecture/ER_DATA_MODEL.md` - data model and ER diagram notes
- `evidence/DEPLOYMENT_EVIDENCE.md` - Docker/Kubernetes/API proof checklist
- `screenshots/README.md` - screenshot naming convention and capture checklist

## Quick Start

1. Capture all required screenshots and save them under `docs/screenshots/`.
2. Fill in command outputs and observations in `docs/evidence/DEPLOYMENT_EVIDENCE.md`.
3. Add your API collection/spec links to `docs/api/API_DOCUMENTATION.md`.
4. Add ER diagram image and model notes in `docs/architecture/ER_DATA_MODEL.md`.
